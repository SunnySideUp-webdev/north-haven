# North Haven low-fidelity wireframes

Status: Draft for product review

These wireframes validate hierarchy, information density, navigation, and the
evening-to-morning workflow. They intentionally avoid final typography,
illustration, detailed color, shadows, and component styling.

## Fidelity rules

- Lavender and blush are used only to communicate intended surface hierarchy.
- Text represents realistic English interface content.
- Measurements are directional, not implementation specifications.
- Every screen targets a 1440 px desktop canvas.
- Decorative icons and mascots are intentionally absent.
